DECLARAÇÃO, CIÊNCIA E PROTEÇÃO DE DADOS

🔒 Aviso de Privacidade e Uso das Informações
Finalidade

As informações são coletadas para auxiliar na preparação, conferência e realização do Cadastro Nacional da Agricultura Familiar – CAF e nas atividades relacionadas ao atendimento da agricultura familiar.

Dados coletados

O formulário poderá coletar informações de identificação, contato, endereço, composição familiar, propriedade, áreas, produção, renda, documentos e demais informações necessárias à finalidade informada.

Armazenamento inicial

Os dados preenchidos são inicialmente armazenados localmente no dispositivo utilizado para o preenchimento. O formulário não realiza automaticamente o envio dos dados pessoais para servidor ou banco de dados externo.

Arquivo JSON

Ao utilizar a opção "Salvar como", o sistema gera um arquivo JSON contendo as informações preenchidas no formulário e realiza o download desse arquivo para o dispositivo utilizado.

Responsabilidade pelo arquivo

Após o download, o arquivo deverá ser armazenado e tratado de maneira segura pelo responsável pelo atendimento, evitando acesso, cópia, divulgação ou compartilhamento indevido das informações pessoais nele contidas.

Finalidade posterior

O arquivo poderá ser utilizado pelo responsável pelo atendimento para conferência das informações e preparação/realização do cadastro oficial do CAF, observada a legislação aplicável.

LGPD

O tratamento das informações deverá observar os princípios e regras estabelecidos pela Lei nº 13.709/2018 – Lei Geral de Proteção de Dados Pessoais (LGPD).

• Estou ciente de que os dados preenchidos neste formulário são inicialmente armazenados localmente neste dispositivo e que o formulário não realiza, por si só, o envio automático das informações para um servidor ou banco de dados externo.

• Estou ciente de que as informações poderão ser utilizadas pelo responsável pelo atendimento para conferência, organização e posterior realização do cadastro oficial, observada a legislação aplicável, especialmente a Lei nº 13.709/2018 (Lei Geral de Proteção de Dados Pessoais – LGPD).

• Declaro, ainda, estar ciente de que o preenchimento deste formulário não constitui, por si só, a realização ou aprovação do CAF, servindo como etapa preparatória para o atendimento e cadastro oficial.
